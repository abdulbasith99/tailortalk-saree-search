# 🧵 TailorTalk — AI-Powered Saree Visual Search Agent

An AI agent that finds visually similar sarees from a catalogue of **1,000+ designs**. The agent chats naturally, understands when a similarity search is being requested, takes an image (upload or URL), searches a vector index, and returns the closest matches with similarity scores.

## 🚀 Live Demo

https://tailortalk-saree-search-y7kxkpjtfjf7ftl2iubqnh.streamlit.app



## ✨ Features

- **Natural Language Chat** — Ask "find similar sarees" or just chat; the AI agent understands intent
- **Image Upload or URL** — Provide a saree image via file upload or paste a direct image URL
- **Fine-Grained Visual Search** — Multi-view CLIP embeddings capture border, pallu, motifs, fabric, and colour
- **1,000+ Saree Catalogue** — Real saree images from a fashion e-commerce dataset
- **Similarity Scores** — Every match includes a confidence percentage
- **Rich Metadata** — Product names, SKUs, and source URLs displayed with results

## 🛠️ Technical Stack

| Component | Choice |
|-----------|--------|
| **Vector Database** | ChromaDB (persistent, cosine distance) |
| **Embedding Model** | CLIP ViT-B/16 via `sentence-transformers` |
| **Agent Framework** | LangChain function-calling with OpenAI GPT-4o-mini |
| **Frontend** | Streamlit chat interface |
| **Image Processing** | Pillow (PIL) |

## 🚀 Getting Started

### 1. Clone & Install

```bash
git clone <your-repo-url>
cd TailorTalk-project
pip install -r requirements.txt
```

### 2. Dataset

The `data/` folder in this repo already contains the saree image dataset (1,000+ images), and `image_metadata.csv` maps each filename to its product name, SKU, and source URL.

### 3. Index the Images

Build the ChromaDB vector store:

```bash
python index_data.py
```

This extracts multi-view CLIP embeddings (full image + center crop + top/bottom border strips) and stores them in `chroma_db/`. This only needs to be run once — or again if you update the dataset.

### 4. Run the App

```bash
python -m streamlit run app.py
```

### 5. (Optional) Add OpenAI API Key

For the full AI agent experience, add your OpenAI API key in the sidebar. Without it, TailorTalk uses a built-in rule-based intent detector that still performs visual searches.

## 🔍 How Search Quality Was Improved

The assignment notes that basic embedding search returns loose results on this dataset because all images are sarees with fine-grained differences. Here's how TailorTalk addresses this:

1. **Higher-Capacity CLIP Model** — Uses `clip-ViT-B/16` instead of the smaller `clip-ViT-B/32` for better fine-grained visual discrimination.

2. **Multi-View Embedding Fusion** — Each saree image is embedded from 4 views:
   - **Full image** — captures overall design and colour composition
   - **Center crop** — captures the main body pattern/motifs
   - **Top strip** — captures the pallu/border work
   - **Bottom strip** — captures the border detail
   
   These embeddings are L2-normalised and averaged, producing a richer representation that captures saree-specific features.

3. **Cosine Distance** — ChromaDB is configured with cosine distance, which is the correct metric for CLIP embeddings.

4. **Rich Metadata** — Product names, SKUs, and source URLs are stored alongside embeddings, enabling the agent to present meaningful results.

## 🤖 Agent Tool Schema

The LangChain agent exposes a single callable tool:

```python
@tool
def search_similar_sarees(image_input: str, top_k: int = 4) -> str:
    """
    Search for visually similar sarees from the catalogue.

    Args:
        image_input: Path to a local image file OR a URL to an image of a saree.
        top_k: Number of results to return (1-10, default 4).

    Returns:
        Formatted list of matching sarees with similarity scores.
    """
```

The LLM (GPT-4o-mini) decides when to call this tool based on natural conversation, understanding phrases like "find similar", "show me similar sarees", "match this", etc.

## ⚠️ Assumptions & Trade-offs

1. **Local ChromaDB** — Uses a local persistent ChromaDB store rather than a cloud vector DB. This keeps the app self-contained and deployable without external services.

2. **Optional OpenAI API Key** — The full AI agent requires an OpenAI API key. Without it, a rule-based fallback handles basic intent detection and still performs visual searches.

3. **CLIP Model Size** — The ViT-B/16 model is larger than ViT-B/32, requiring more memory but providing better search quality.

4. **Repo Size** — Bundling 1,000+ images directly in the repo increases its size. This trade-off was chosen for deployment simplicity (no external download step needed at runtime).
